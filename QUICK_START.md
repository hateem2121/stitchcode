# 🚀 Quick Start Guide for StitchCode

## For 5th Graders (and everyone else!)

### Option 1: Use It Right Now! ⚡
1. Open your web browser
2. Go to: **https://hateem2121.github.io/stitchcode/**
3. Start making QR codes! ✨

**No download needed!** It works in your browser and remembers your work.

---

### Option 2: Download the App 💾

#### For Mac:
1. Download `StitchCode-mac.zip` from the Releases page
2. Double-click to unzip it
3. Drag `StitchCode.app` to Applications
4. Open it from Applications folder

#### For Windows:
1. Download `StitchCode Setup.exe` from the Releases page
2. Double-click to run it
3. Click "Next" a few times
4. Find it in Start Menu

#### For Linux:
1. Download `StitchCode.AppImage` from the Releases page
2. Right-click → Properties → Permissions → Check "Allow as program"
3. Double-click to run!

---

### What Can You Make?

| Type | What It Does |
|------|--------------|
| 🔗 Link | Opens a website when scanned |
| 📝 Text | Shows a message when scanned |
| 📶 WiFi | Lets people join your WiFi easily |
| 👤 Contact Card | Shares your phone number and info |
| 📧 Email | Opens an email ready to send |
| 💬 Message | Opens texting app with your message |
| ☎️ Phone Number | Calls a number when scanned |

---

### How to Make a QR Code

1. **Pick what you want to share** (like a website link)
2. **Type it in** the box
3. **Add a picture** if you want (your photo, a logo, anything!)
4. **Watch it check itself** — it scans the code to make sure it works!
5. **Download** as PNG or print it out

✅ If you see a green checkmark, it works!
❌ If you see a red X, click "Fix it for me" button

---

### Tips for Best Results

- ✅ Use dark colors on light paper
- ✅ Make it at least 2 cm (thumb size) when printing
- ✅ Leave some empty space around the edges
- ✅ Test it with your phone before printing lots!
